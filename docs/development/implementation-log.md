# Simple Sigh — implementation log (M1/M2)

Technical decisions taken during implementation, with the evidence used. The
private Superpowers ledger (`.superpowers/`, git-ignored) mirrors these entries.

States are reported separately: **static/XML**, **unit tests**, **compile**, **in-game**.
Nothing in this log claims in-game success; in-game checks are `NOT RUN` unless stated.

## Environment (2026-10-21)

- .NET SDK 10.0.402 installed in the cloud container (not in the ZIP).
- `rimworld_DLL.zip` (SHA-256 `dab2b7f3…a279`, matches the audit) extracted **outside** the repository.
- API study by decompiling the reference assemblies locally (ILSpy). Decompiled output is not committed.
- No RimWorld executable is available → every in-game check is `NOT RUN`.

## Decisions

| # | Decision | Evidence / reason | Cost if wrong |
| --- | --- | --- | --- |
| D1 | Work on branch `claude/sleepy-galileo-k24tf3` (no extra worktree) | Branch is mandated by the session and isolated from `main` | none |
| D2 | `Assembly-CSharp`, `Waylith`, `UnityStubs` all target `net10.0` / C# 14 | Decompiled csproj metadata of the 1.7 references | — |
| D3 | Textures are generated by `tools/textures/generate_textures.py` (original procedural pixel art, CutoutComplex masks) | The ZIP has no building sprites; game art must not be copied | art quality only |
| D4 | Display panel is left **untinted** via the mask's black area | 1.7 `Shaders/Map/CutoutComplex.frag.glsl`: `colMultiplier = mask.r * (_Color*vColor) + (1-mask.r)` → mask black keeps the texture colour | text contrast on dark stuff |
| D5 | Structural tests resolve `ParentName` inside the mod and optionally cross-check Core names when `RIMWORLD_REFERENCE_DIR` is set | Inherited fields (stuffCategories) live in the abstract base | test-only |
| D6 | Saved text goes through `SignTextCodec` (`|`-wrapped, `%25 %5C %0A %0D` escapes) | 1.7 `ParseHelper.ParseString` rewrites the two characters `\n` into a newline on load; `ScribeLoader` uses `XmlDocument` (whitespace-only text dropped). Unit tests replay that path | save format must stay readable by this decoder |
| D7 | `SignTextRules` also rejects TAB, C0/C1 controls, lone surrogates | Such characters break XML saves; spec forbids silently deleting text | users cannot paste tabs |
| D8 | Build references come from `RIMWORLD_REFERENCE_DIR` (or `RIMWORLD_GAME_DIR`, probing `RimWorldWin64_Data/Managed`) | The supplied ZIP is a reference folder, not a game install | HintPath tweak |
| D9 | No Harmony | All hooks needed are public virtuals: `ThingComp.PostDraw/PostExposeData/CompGetGizmosExtra/PostDeSpawn` | — |
| D10 | Text size is a user scale in [0.3, 1.0] of the largest size that fits the panel | Text must stay inside the panel, so "bigger than fits" is not offered | UX only |
| D11 | Copy/paste text gizmos (session clipboard, values only) | Spec M1 lists copy/move/deconstruct checks; cheap and avoids Thing references in statics | none |
| D12 | Kept the plan's namespace `SimpleSigh.Text`; game-side files alias `Verse.Text` as `GameText` | Inside `SimpleSigh.*`, `Text` resolves to the namespace first | none |
| D13 | World text = glyph quads from `UnityStubs.Gui.TextMeshProBackend` (medium UI font index) drawn with shader `World/WorldText` | UnityStubs' own `TMPro.TextMeshPro` builds world text exactly this way in 1.7; `UnityEngine.TextMesh` is an empty stub; GUI→RenderTexture behaviour lives in the (absent) backend implementation | renderer rewrite if the backend behaves differently in game |
| D14 | Render queue 3000 | `Shaders.Map.xml`: Cutout 2900, LightOverlay 3100, FogOfWar 3175; WorldText default 3610 would glow at night and show through fog | visual only |
| D15 | Glyph atlas is alpha coverage (not SDF) | `Shaders/World/WorldText.frag.glsl` uses `texture(_MainTex).a` as coverage | — |
| D16 | Unknown glyphs → one `?` per user-perceived character + inspect-pane note; display-only NFC (か+゛→が) | Spec: unsupported glyphs must be identifiable, saved text unchanged | — |
| D17 | Any glyph quad outside the padded panel is dropped (`ClipTo`) | Guarantees text never leaves the board even if a font metric is off | partially hidden text in edge cases |
| D18 | `SignLayout.Fit` introduced in M1 (single-line); M2 extends it with wrapping | Plan's M2 interface; avoids a throwaway M1 fitter | none |
| D19 | Render cache keyed by values (text, RGBA, size, rotation, atlas version, font, panel geometry hash) instead of a version counter | Loading or future code paths cannot forget to bump a counter; key equality is unit-tested | none |
| D20 | Mesh release on `PostDeSpawn`, `PostDestroy`, `Notify_MapRemoved` (`notifyMapRemoved=true`), and a `GameComponent` ctor calling `ReleaseAll` | 1.7 `ThingWithComps.Notify_MyMapRemoved` only notifies comps when `def.notifyMapRemoved`; `Game.FillComponents`/load create one GameComponent per game; old games' things are never despawned | GPU memory leak if a path is missed |
| D21 | Materials come from vanilla `MaterialPool` (never destroyed by us) | Keys are quantised Color32 + atlas + shader + queue, so pool growth is bounded by distinct colours | none |
