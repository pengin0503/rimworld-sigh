private Superpowers ledger (`.superpowers/`, git-ignored) mirrors these entries.

## Decisions

| # | Decision | Evidence / reason | Cost if wrong |
| --- | --- | --- | --- |
| D1 | Work on branch `claude/sleepy-galileo-k24tf3` (no extra worktree) | Branch is mandated by the session and isolated from `main` | none |

| D11 | Copy/paste text gizmos (session clipboard, values only) | Spec M1 lists copy/move/deconstruct checks; cheap and avoids Thing references in statics | none |
